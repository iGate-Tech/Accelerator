<project_specification>
  <project_name>Accelerator</project_name>

  <overview>
    AI-powered startup accelerator tool built with SolidJS that guides founders through a comprehensive 60+ step validation and acceleration process. The application provides an intelligent, interactive platform for startup ideation, validation, planning, and execution with AI-powered simulations and guidance using LLMs (OpenRouter). Features include project management, task tracking, credit-based AI usage system, user authentication, portfolio organization, and collaborative features. The application uses client-side PGLite database with IndexedDB persistence for offline-capable operation, with a Node.js/Express backend for LLM API integration.
  </overview>
